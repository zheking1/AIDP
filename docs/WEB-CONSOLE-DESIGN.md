# AIDP Tools Web Console 设计文档

## 1. 概述

为 5 个 AIDP 工具提供统一风格的 Web 控制台，用于管理、监控和操作各工具功能。

### 1.1 设计原则

- **统一技术栈**: Jinja2 + Alpine.js + Tailwind CSS CDN（无构建步骤）
- **统一布局**: 顶部导航 + 侧边栏 + 内容区
- **统一风格**: 白色卡片、圆角、阴影、蓝色主色调
- **纯 API 驱动**: 前端通过 REST API 与后端交互
- **轻量级**: 不引入 Node.js/TypeScript，Python 全栈

### 1.2 端口分配

| 工具 | 端口 | Web UI 路径 |
|------|------|-------------|
| knowledge-tool | 18081 | `/` |
| asset-tool | 18082 | `/` |
| sandbox-tool | 18083 | `/` |
| quality-tool | 18084 | `/` |
| memory-tool | 18085 | `/` |

## 2. 统一布局设计

### 2.1 基础模板 (base.html)

```
┌─────────────────────────────────────────────┐
│  顶部导航栏 (Logo + 工具名 + 健康状态)      │
├──────────┬──────────────────────────────────┤
│          │                                  │
│  侧边栏  │         内容区                   │
│  (导航)  │   (卡片/表格/表单/代码编辑器)     │
│          │                                  │
│          │                                  │

```

### 2.2 颜色系统

- 主色: `blue-500` (#3B82F6)
- 成功: `green-500`
- 警告: `yellow-500`
- 错误: `red-500`
- 背景: `gray-50`
- 卡片: `white` + `shadow-sm`

### 2.3 公共组件

- `nav.html`: 顶部导航栏
- `sidebar.html`: 侧边栏菜单
- `pagination.html`: 分页组件
- `toast.html`: 消息提示
- `modal.html`: 弹窗组件
- `code-editor.html`: 代码编辑器（textarea + monospace）

## 3. 各工具 Web Console 详细设计

---

### 3.1 Knowledge Tool Web Console

**端口**: 18081
**功能**: 文档知识库管理

#### 3.1.1 页面列表

| 页面 | 路径 | 功能 |
|------|------|------|
| 仪表盘 | `/` | 统计概览、最近文档、索引状态 |
| 文档列表 | `/documents` | 浏览/搜索/筛选文档 |
| 文档详情 | `/documents/{id}` | 查看文档内容、块、索引状态 |
| 上传文档 | `/documents/new` | 上传 Markdown/文本文件 |
| 搜索测试 | `/search` | 测试搜索效果 |

#### 3.1.2 仪表盘 `/`

显示内容：
- 文档总数
- 已索引文档数
- 待索引文档数
- 最近 5 个文档
- 快捷操作按钮

#### 3.1.3 文档列表 `/documents`

表格列：
- 标题（链接到详情）
- 类型 (markdown/plain)
- 状态 (indexed/pending/error)
- 创建时间
- 操作（查看/删除）

筛选项：
- workspace_id (下拉)
- doc_type (下拉)
- index_status (下拉)

#### 3.1.4 文档详情 `/documents/{id}`

显示内容：
- 文档元信息
- 内容预览
- 索引状态
- 文档块列表
- 操作按钮（重新索引/删除）

#### 3.1.5 上传文档 `/documents/new`

表单：
- workspace_id (必填)
- project_id (可选)
- title (必填)
- doc_type (markdown/plain)
- content (文本框)
- 提交按钮

#### 3.1.6 搜索测试 `/search`

- 搜索输入框
- workspace_id 筛选
- top_k 设置
- 搜索结果列表（分数、内容片段、来源）

| 模板渲染 | `/render` | 测试模板渲染 |

#### 3.2.2 仪表盘 `/`

显示内容：
- 资产总数
- 按类型分布 (snippet/config/pattern)
- 最近 5 个资产
- 快捷操作按钮

#### 3.2.3 资产列表 `/assets`

表格列：
- 标题
- 类型 (snippet/config/pattern)
- 语言
- 标签
- 创建时间
- 操作（查看/编辑/删除）

- 变量输入（JSON 或 key-value）
- 渲染结果展示

### 3.3 Sandbox Tool Web Console

**端口**: 18083
**功能**: 代码执行沙箱

#### 3.3.1 页面列表

| 页面 | 路径 | 功能 |
|------|------|------|

#### 3.3.2 执行器 `/` (主页)

布局：
```
┌─────────────────────────────────────────┐
│  语言选择: [Python ▼]  [执行按钮]       │
├─────────────────────────────────────────┤
│  代码编辑器 (textarea, monospace)       │
│                                         │
│                                         │
├─────────────────────────────────────────┤
│  输入 (stdin, 可折叠)                   │
├─────────────────────────────────────────┤
│  输出区                                 │
│  ┌─ stdout ─────────────────────────┐   │
│  │ (绿色文字)                       │   │
│  └──────────────────────────────────┘   │
│  ┌─ stderr ─────────────────────────┐   │
│  │ (红色文字)                       │   │
│  └──────────────────────────────────┘   │
│  状态: exit_code=0 | 125ms             │
└─────────────────────────────────────────┘
```

#### 3.3.3 执行历史 `/history`

表格列：
- ID
- 语言
- 代码预览 (前 50 字符)
- 退出码
- 耗时
- 创建时间
- 操作（查看详情）

## 4. 公共 API 端点

每个工具需新增以下公共端点支持 Web UI：

### 4.1 统计端点

```
GET /api/stats
Response: {
    "total": 100,
    "by_type": {"snippet": 30, "config": 20},
    "recent": [...]
}
```

### 4.2 历史端点 (sandbox/quality)

```
GET /api/{resource}/history?limit=20
GET /api/{resource}/history/{id}
```

## 6. 依赖

无需新增依赖，现有 `requirements.txt` 已包含：
- `jinja2` — 模板引擎
- `aiofiles` — 静态文件服务

## 7. 开发顺序

1. **knowledge-tool** — 最复杂，有文档/块/索引概念
2. **asset-tool** — 类似 knowledge，有模板渲染
3. **sandbox-tool** — 代码编辑器 + 执行
4. **quality-tool** — 类似 sandbox，结果展示更复杂
5. **memory-tool** — 最简单，CRUD 为主
