## 1. 系统定位

### 1.1 核心问题

AI Agent 在编程时面临：
- 不了解项目结构和代码
- 不知道项目文档和规范
- 缺乏项目经验积累
- 上下文窗口有限，容易溢出

### 1.2 解决方案

AIDP 提供一套完整的 AI 编程基础设施：
- **理解层**: 帮助 AI 理解代码和文档
- **执行层**: 帮助 AI 执行和检查代码
- **记忆层**: 帮助 AI 积累项目经验
- **优化层**: 管理 AI 上下文，防止溢出
- **进化层**: 系统自我改进，从错误和成功中学习

## 4. 协作流程

### 4.1 理解需求

```
AI Agent: "用户要求增加 JWT 认证"
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  Context Optimizer 分析任务                                  │
│  → 需要: 文档理解 + 代码理解 + 经验参考                     │
│  → 预算: knowledge 2000tok, code-index 3000tok, memory 1000tok │
└─────────────────────────────────────────────────────────────┘
    │
    ├─► Knowledge Tool: 搜索 JWT 相关文档
    │   → 返回: docs/auth/jwt-guide.md (摘要 800tok)
    │
    ├─► Code Index: 查找现有认证代码
    │   → 返回: AuthController, TokenService (摘要 1200tok)
    │
    ├─► Doc Index: 获取文档-代码链接
    │   → 返回: jwt-guide.md → TokenService.createToken() (400tok)
    │
    └─► Memory Tool: 查找类似经验
        → 返回: "上次增加 OAuth 时遇到 token 过期问题" (200tok)
```

### 4.2 编写代码

```
AI Agent: "开始编写 JWT 认证代码"
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  Context Optimizer 分析任务                                  │
│  → 需要: 代码模板 + 架构参考 + 规范检查                     │
│  → 预算: asset 2000tok, code-index 2000tok, knowledge 1000tok │
└─────────────────────────────────────────────────────────────┘
    │
    ├─► Asset Tool: 获取 JWT 代码模板
    │   → 返回: jwt-filter-template.java (摘要 800tok)
    │
    ├─► Code Index: 查询现有架构
    │   → 返回: SecurityConfig 配置方式 (摘要 800tok)
    │
    └─► Knowledge Tool: 查阅编码规范
        → 返回: 命名规范、异常处理规范 (摘要 400tok)
```

### 4.3 验证代码

```
AI Agent: "验证编写的代码"
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  Context Optimizer 分析任务                                  │
│  → 需要: 执行代码 + 质量检查                                 │
│  → 预算: sandbox 3000tok, quality 2000tok                   │
└─────────────────────────────────────────────────────────────┘
    │
    ├─► Sandbox Tool: 执行单元测试
    │   → 返回: 测试通过，覆盖率 85% (摘要 1000tok)
    │
    └─► Quality Tool: 代码质量检查
        → 返回: 0 错误, 2 警告 (摘要 500tok)
```

### 4.4 学习积累

```
AI Agent: "完成任务，记录经验"
    │
    ▼
┌─────────────────────────────────────────────────────────────┐
│  Memory Tool 记录本次经验                                    │
│                                                             │
│  - 决策: 使用 JWT + Refresh Token 双 token 方案            │
│  - 原因: 安全性 + 用户体验                                  │
│  - 问题: token 过期后需要重新登录                            │
│  - 解决: 实现 refresh token 自动续期                        │
│  - 相关文件: AuthController.java, TokenService.java         │
└─────────────────────────────────────────────────────────────┘
```

```
AI Agent ──► Context Optimizer ──► 需求分析 ──► 预算分配 ──► Skill Router
                                                                    │
                                    ┌───────────────────────────────┘
                                    ▼
                            ┌─────────────────┐
                            │  工具选择       │
                            │  并行/串行策略  │
                            └─────────────────┘
                                    │
                    ┌───────────────┼───────────────┐
                    ▼               ▼               ▼
              ┌──────────┐   ┌──────────┐   ┌──────────┐
              │ Tool 1   │   │ Tool 2   │   │ Tool 3   │
              │ [预算]   │   │ [预算]   │   │ [预算]   │
              └──────────┘   └──────────┘   └──────────┘
                    │               │               │
                    └───────────────┼───────────────┘

                            ┌─────────────────┐
                            │  结果精简       │
```
