## 1. 项目概述

### 1.1 项目背景

当前系统缺乏安全机制，存在以下风险：
- 沙箱无隔离，可入侵宿主机
- 输入无验证，可注入攻击
- API 无鉴权，可未授权访问
- 密钥明文存储，可泄露
- 并发无控制，可数据竞争

### 1.2 项目目标

提供基础安全保障：
- 沙箱隔离：Docker 容器 + 资源限制
- 输入验证：参数校验 + 路径过滤
- API 鉴权：JWT token + 审计日志
- 并发控制：文件级锁 + 修改排队
- 密钥管理：环境变量
- 调用统计：Redis 计数

## 3. 非功能需求

### 3.1 性能

| 需求 | 指标 |
|------|------|
| **NFR-01** | 沙箱启动时间 < 5s |
| **NFR-02** | 认证延迟 < 100ms |
| **NFR-03** | 审计日志写入 < 50ms |

### 3.2 可靠性

| 需求 | 指标 |
|------|------|
| **NFR-10** | 沙箱执行失败不影响宿主机 |
| **NFR-11** | 审计日志不丢失 |
| **NFR-12** | Token 刷新不中断服务 |

### 3.3 可用性

| 需求 | 指标 |
|------|------|
| **NFR-20** | 认证错误提示清晰 |
| **NFR-21** | 权限不足提示清晰 |
| **NFR-22** | 审计日志可查询 |

### 3.4 安全性

| 需求 | 指标 |
|------|------|
| **NFR-30** | 密码哈希存储 |
| **NFR-31** | Token 过期自动失效 |
| **NFR-32** | 敏感操作记录审计 |

## 4. 用户故事

### 4.1 管理员用户故事

**US-01**: 作为管理员，我需要登录系统，以便管理用户和查看统计
- 输入: 用户名 + 密码
- 输出: JWT token

**US-02**: 作为管理员，我需要查看用户列表，以便了解系统用户
- 输入: 无
- 输出: 用户列表

**US-03**: 作为管理员，我需要创建用户，以便团队成员使用
- 输入: 用户名 + 密码 + 角色
- 输出: 创建成功

**US-04**: 作为管理员，我需要查看审计日志，以便追溯操作
- 输入: 筛选条件
- 输出: 审计日志列表

**US-05**: 作为管理员，我需要查看调用统计，以便了解系统使用情况
- 输入: 日期
- 输出: 统计数据

### 4.2 普通用户故事

**US-10**: 作为用户，我需要登录系统，以便使用工具
- 输入: 用户名 + 密码
- 输出: JWT token

**US-11**: 作为用户，我需要执行代码，以便验证结果
- 输入: 代码
- 输出: 执行结果

**US-12**: 作为用户，我需要查看自己的调用统计，以便了解使用情况
- 输入: 无
- 输出: 个人统计
