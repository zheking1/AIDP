# AIDP 开发计划 - 2026-07-06

## 已完成的修改

### 1. File Watcher 服务（新增）
路径：`tools/file-watcher/`

功能：
- 使用 watchdog 监听本地源代码目录变化
- 自动触发 code-index 增量索引
- 防抖处理（1秒内多次变化只触发一次）
- 支持添加/移除/重扫监听项目

API端点：
- `POST /api/watcher/projects` - 添加监听项目
- `GET /api/watcher/projects` - 列出所有监听项目
- `GET /api/watcher/projects/{id}` - 获取项目详情
- `PATCH /api/watcher/projects/{id}` - 更新项目配置
- `DELETE /api/watcher/projects/{id}` - 移除监听项目
- `POST /api/watcher/projects/{id}/rescan` - 重新全量扫描
- `GET /api/watcher/projects/{id}/events` - 查看事件日志
- `GET /api/watcher/stats` - 统计信息

### 2. 配置文件导入逻辑修改
路径：`tools/project-importer/app/main.py`

修改内容：
- 配置文件（.yml/.properties/.env等）导入到 knowledge-tool（doc_type="config"）
- 同时保留导入到 Controller configs 的兼容（onboarding_import 流程）
- 支持按环境分类（dev/test/prod）

### 3. Init 幂等操作
路径：`apps/controller/app/services/project_init_service.py`

修改内容：
- 多次 init 同一项目时，更新已有项目而非重复创建
- 返回 `is_update: true/false` 标识

### 4. 删除本地文件功能
路径：`tools/project-importer/app/main.py`

新增参数：
- `delete_local_docs`: 导入成功后删除本地文档
- `delete_local_configs`: 导入成功后删除本地配置文件

### 5. 导出 API
路径：`tools/project-importer/app/main.py`

新增端点：
- `POST /api/export/docs` - 从 AIDP 导出文档到本地
- `POST /api/export/configs` - 从 AIDP 导出配置到本地

### 6. 清理脚本
路径：`tools/scripts/clear_all_projects.py`

功能：清除所有 AIDP 工具中的项目数据（Controller、code-index、knowledge、memory、asset）

### 7. SQLite 兼容性修复
修改的文件：
- `tools/knowledge-tool/app/db/init_db.py`
- `tools/memory-tool/app/db/init_db.py`
- `tools/asset-tool/app/db/init_db.py`
- `apps/controller/app/db/init_db.py`

修改内容：将 PostgreSQL 语法改为 SQLite 兼容语法（VARCHAR/TEXT/TIMESTAMP）

## File Watcher 配置示例

```bash
# 添加监听项目
curl -X POST http://localhost:18091/api/watcher/projects \
  -H "Content-Type: application/json" \
  -d '{
    "project_name": "openCode",
    "local_path": "/path/to/openCode",
    "code_index_project_id": 1,
    "ignored_dirs": [".git", "node_modules", "__pycache__", ".venv"],
    "ignored_patterns": ["*.pyc", "*.log"]
  }'

# 查看监听项目
curl http://localhost:18091/api/watcher/projects

# 触发重新扫描
curl -X POST http://localhost:18091/api/watcher/projects/1/rescan
```
