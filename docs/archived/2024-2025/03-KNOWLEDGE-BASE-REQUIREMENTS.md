## 1. 项目概述

### 1.1 项目背景

大型项目（如 ruoyi-cloud-plus）有大量文档（README、API 文档、架构文档、代码注释），这些文档与代码之间存在关联，但缺乏有效的管理方式。需要一个知识库工具来：
- 索引项目文档
- 自动生成 Wiki
- 链接文档与代码
- 检测文档过期

### 1.2 项目目标

- 支持 AI Agent 快速理解项目文档
- 自动维护文档与代码的关联
- 提供语义搜索能力
- 检测文档过期并告警

## 4. 用户故事

### 4.1 AI Agent 用户故事

**US-01**: 作为 AI Agent，我需要搜索项目文档，以便理解项目背景
- 输入: "JWT 认证怎么实现"
- 输出: 相关文档列表（摘要 + 链接）

**US-02**: 作为 AI Agent，我需要获取文档关联的代码，以便理解实现细节
- 输入: 文档 ID
- 输出: 关联的代码函数/类列表

**US-03**: 作为 AI Agent，我需要检测文档过期，以便避免使用过时信息
- 输入: 文档 ID
- 输出: 过期列表（过期类型、严重程度）

### 4.2 开发者用户故事

**US-10**: 作为开发者，我需要导入项目文档，以便建立知识库
- 输入: 文件路径
- 输出: 导入成功/失败

**US-11**: 作为开发者，我需要查看知识图谱，以便理解文档关系
- 输入: 无
- 输出: 可视化图谱

**US-12**: 作为开发者，我需要审核 LLM 生成的内容，以便确保质量
- 输入: 审核项 ID + 操作
- 输出: 审核成功
