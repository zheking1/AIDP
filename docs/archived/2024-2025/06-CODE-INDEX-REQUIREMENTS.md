## 1. 项目概述

### 1.1 项目背景

大型项目（如 ruoyi-cloud-plus）有大量代码（850+ Java 文件、12000+ 函数），AI Agent 需要快速理解代码结构，但缺乏有效的索引方式。需要一个代码索引工具来：
- 索引代码结构（AST、依赖、API）
- 构建知识图谱（模块、类、函数、关系）
- 支持调用链追踪和影响分析

### 1.2 项目目标

- 支持 AI Agent 快速定位和理解代码
- 提供调用链追踪和影响分析能力
- 支持增量索引和实时同步
- 支持多语言和多框架

## 4. 用户故事

### 4.1 AI Agent 用户故事

**US-01**: 作为 AI Agent，我需要搜索代码符号，以便快速定位代码
- 输入: "AuthController"
- 输出: 符号列表（文件、行号、签名）

**US-02**: 作为 AI Agent，我需要追踪调用链，以便理解代码执行流程
- 输入: "AuthController.login"
- 输出: 调用链（上游/下游）

**US-03**: 作为 AI Agent，我需要分析变更影响，以便评估修改风险
- 输入: "AuthController.java"
- 输出: 影响范围（模块、API）

### 4.2 开发者用户故事

**US-10**: 作为开发者，我需要索引项目，以便理解代码结构
- 输入: 项目路径
- 输出: 索引完成

**US-11**: 作为开发者，我需要查看依赖图，以便理解模块关系
- 输入: 无
- 输出: 可视化依赖图

**US-12**: 作为开发者，我需要检测死代码，以便清理无用代码
- 输入: 无
- 输出: 死代码列表

## 5. 验收标准

### 5.1 Phase 1 验收标准

- [ ] 能扫描 ruoyi-cloud-plus
- [ ] 能列出所有模块和文件
- [ ] 能搜索类名/函数名（FTS5）
- [ ] 能获取符号定义和源码
- [ ] 索引时间 < 60s（1000 文件）
- [ ] 增量索引 < 5s（单文件变更）
- [ ] 多项目并行索引不冲突
- [ ] 索引失败自动重试 3 次

### 5.2 Phase 2 验收标准

- [ ] 能构建调用关系图
- [ ] 能查询函数调用链（上下游）
- [ ] 能分析代码变更影响范围
- [ ] 能显示模块依赖关系
- [ ] 调用链查询 < 100ms
- [ ] 能追踪接口→实现
- [ ] 能解析回调目标
- [ ] CLI 支持搜索/追踪/统计

### 5.3 Phase 3 验收标准

- [ ] 文件修改后自动更新索引（< 5s）
- [ ] 能识别 Spring Boot @RestController
- [ ] 能识别 FastAPI @app.get
- [ ] 支持 Python 项目索引
- [ ] 支持 TypeScript 项目索引
- [ ] 能检测死代码
- [ ] 能链接跨服务 HTTP 调用
- [ ] 支持 Cypher 查询
- [ ] 索引体积减少 30%+

### 5.4 Phase 4 验收标准

- [ ] 能检测社区划分
