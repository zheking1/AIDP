系统简介

AIDP (AI DevOps Platform) 是一个统一的 AI 编程工具管理平台，帮助你管理和组织各种 AI 开发工具和能力。

核心功能包括：

  • 工具管理 — 注册、发现和监控 AI 编程工具
  • 知识中心 — 文档管理、搜索和知识库
  • AI 技能 — 创建和管理 AI 助手技能
  • 规则引擎 — 代码风格和审查规则
  • MCP 集成 — 通过 Model Context Protocol 与 AI 编辑器集成

MCP 配置

MCP (Model Context Protocol) 是 AI 编辑器与 AIDP 平台之间的通信协议。通过 MCP，你可以在 VS Code、Cursor 等编辑器中直接调用 AIDP 的功能。

MCP 服务器地址

http://<your-server>:8883/mcp

VS Code 配置示例

{ "mcpServers": { "aidp": { "url": "http://localhost:8883/mcp", "headers": { "Authorization": "Bearer YOUR_API_KEY" } } } }

Cursor 配置示例

{ "mcpServers": { "aidp": { "type": "http", "url": "http://localhost:8883/mcp", "headers": { "Authorization": "Bearer YOUR_API_KEY" } } } }
请先获取 API Key 并在配置中替换 YOUR_API_KEY

获取 API Key

API Key 用于身份认证，确保只有授权的用户和应用可以访问 AIDP 平台。

操作步骤

  1. 点击右上角用户头像，选择 「API 密钥」
  2. 点击 「创建密钥」 按钮
  3. 为密钥输入一个名称（如 "VS Code MCP"）
  4. 选择过期时间（建议选择不过期或 90 天）
  5. 点击创建，立即复制并保存密钥
密钥关闭后将无法再次查看，请妥善保管。

模型配置

AI 模型配置决定了 AI 审查、分类等功能使用的模型。你可以在用户配置中设置偏好的模型参数。

支持的模型提供商

  • OpenAI — GPT-4o, GPT-4o-mini, o3-mini 等
  • DeepSeek — DeepSeek-V3, DeepSeek-R1 等
  • 通义千问 — Qwen 系列
  • 兼容 OpenAI API — 任何兼容 OpenAI 接口的服务

配置参数说明

参数 说明 默认值
provider模型提供商openai
api_baseAPI 地址https://api.openai.com/v1
model_name模型名称gpt-4o
api_keyAPI 密钥—
max_tokens最大输出 Token 数4096
temperature生成温度 (0-2)0.3

配置 DeepSeek 示例

{ "provider": "deepseek", "api_base": "https://api.deepseek.com/v1", "model_name": "deepseek-chat", "api_key": "sk-xxxxxxxxxxxxxxxx", "max_tokens": 8192, "temperature": 0.3 }
