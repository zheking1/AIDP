接入 AI Agent

在你的 MCP 配置中添加 AIDP Controller 地址，AI Agent 即可调用所有平台能力。需在模型管理页面配置 API Key。

{"mcpServers":{"aidp":{"url":"http://192.168.0.100:8883/mcp","headers":{"x-api-key":"your-key"}}}}

初始化项目

Agent 调用 aidp_init 一键导入：扫描代码 → 索引 → 创建记忆 → 自动生成领域 Agent。

aidp_init(project_name="my-app", tech_stack="Python 3.13+FastAPI", key_files=[{path:"main.py",content:"...",type:"python"}])

开发工作流

每次开发任务必调 aidp_context 加载上下文，系统自动匹配领域 Agent、检索知识和技能。

aidp_context(project_name="aidp", task="修复登录cookie过期", api_key="...")

知识沉淀

完成开发后调 index_changes 索引变更 + 分析模式，优秀经验 promote 为系统级最佳实践。

index_changes(task="修复cookie", changed_files=[{path:"auth.py",content:"...",language:"python"}])

多用户隔离

MCP 认证后每个 session 自动绑定用户和项目，后续调用只返回该用户/项目的数据。

x-api-key: sk-your-api-key

领域 Agent

项目初始化时自动根据技术栈生成专属 Agent，aidp_context 根据任务意图自动匹配。

a后端项目自动创建: fastapi-backend / python-security
前端项目: react-frontend / vue3-frontend
