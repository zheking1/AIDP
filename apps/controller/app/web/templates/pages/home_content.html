使用指南

接入 AI Agent

在你的 MCP 配置中添加 AIDP Controller 地址，AI Agent 即可调用所有平台能力。

{"mcpServers":{"aidp":{"url":"http://192.168.0.100:8883/mcp"}}}

初始化项目

Agent 调用 aidp_init 一键导入项目：扫描技术栈、索引代码、创建记忆和领域 Agent。

aidp_init(project_name="my-app", tech_stack="Python 3.13+FastAPI")

知识检索

aidp_context 自动加载项目上下文、匹配技能、检索知识——Agent 开发前必调第一步。

aidp_context(project_name="my-app", task="修复登录bug")

持续进化

完成开发后调用 index_changes 索引变更 + 分析模式，优秀经验自动 promote 为系统最佳实践。

index_changes(task="修复cookie过期", changed_files=[...])
