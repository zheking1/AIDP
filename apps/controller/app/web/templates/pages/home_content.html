系统简介

AIDP 是一个私有化 AI DevOps 平台，通过统一 MCP 协议为 AI Agent 提供项目上下文、代码索引、知识检索、沙箱执行等能力。一个 Controller 承载全部功能。

15 个功能模块|13 个 MCP 工具|5 阶段管线|3 层文件索引

1配置 AI 模型

进入 系统管理 → 模型管理，添加你需要的大模型。每个模型需填写名称、API端点、API Key。

• 聊天模型: 填入 OpenAI 兼容的 API 地址和 Key，task_types 选 "chat"
• 嵌入模型: task_types 选 "embedding"
• 重排模型: task_types 选 "rerank"（端点要填 /v1，不含 /rerank）

2配置 MCP 连接

在你的 AI 编程助手的 MCP 配置中添加：

{"mcpServers": {
  "aidp": {
    "url": "http://192.168.0.100:8883/mcp",
    "transport": "streamable-http",
    "headers": {"x-api-key": "你的API Key"}
  }
}}

API Key 在 系统管理 → API 密钥 中创建，配置到 MCP 的 headers 里。

3初始化项目

Agent 调用 aidp_init 一键导入项目。扫描技术栈、索引代码、创建记忆，并自动生成领域 Agent。

aidp_init(
  project_name="my-project",
  tech_stack="Python 3.13 + FastAPI + PostgreSQL",
  key_files=[{path:"main.py", content:"...", type:"python"}, ...],
  docs=[{title:"README", content:"..."}, ...]
)

4开始开发

每次任务开始前：
aidp_context(project_name="my-project", task="修复登录cookie过期")
系统自动加载项目上下文、匹配 Agent、检索知识和技能。
任务完成后：
index_changes(task="修复cookie", changed_files=[{path:"auth.py",content:"...",language:"python"}], summary="设置httpOnly和secure属性")
索引代码变更 + 分析可复用模式，自动创建进化提案。
a后端项目自动创建: fastapi-backend / python-security
前端项目: react-frontend / vue3-frontend
