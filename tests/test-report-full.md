## 已知问题

### 1. 全局规则 — UI 列表渲染延迟 (非阻塞)

**现象**: API 创建规则成功后，刷新页面 UI 未立即显示新规则，但 API 列表接口返回正确数据。

**原因**: 页面渲染时序问题，Alpine.js `x-for` 列表可能需要额外时间渲染。

**影响**: 低 — API CRUD 功能正常，仅 UI 显示有延迟。

### 2. Agent 文本匹配小问题 (非阻塞)

**现象**: Tab 名称包含空格（`Agent 管理`）导致文本匹配时 `includes('Agent管理')` 失败。

**原因**: 测试断言使用了精确匹配，未考虑文本中的空格差异。

**影响**: 低 — 仅影响测试脚本的断言逻辑，不影响实际功能。
